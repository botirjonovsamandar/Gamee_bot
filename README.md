# Gamee Gold Fest Bot

Автоматизированный клиент для мини-приложения **Gamee** в Telegram: настольная игра с кубиком, ежедневные награды, сезонные призы — всё в одном окне. Поддерживает одновременную работу с несколькими аккаунтами.

---

## Быстрый старт

### 1. Установка

Требуется **Python 3.13+** и Windows.

```powershell
# Создать виртуальное окружение
py -3 -m venv .venv

# Установить зависимости
.\.venv\Scripts\python -m pip install --upgrade pip
.\.venv\Scripts\python -m pip install -r requirements.txt
```

### 2. Первый запуск

```powershell
.\.venv\Scripts\python main.py
```

При первом запуске программа создаст файлы `config.yaml` и `accounts.yaml` автоматически.

### 3. Добавление аккаунтов

1. В главном окне нажмите **«Добавить аккаунт…»** в верхнем меню.
2. Укажите **label** (метку) — уникальное имя аккаунта (например, `Osnova_1`).
3. Укажите **номер телефона** и авторизуйте через Telegram (код подтверждения придёт в Telegram).
4. (Опционально) Укажите **прокси** в формате `socks5://login:pass@host:port`.
5. Нажмите **Сохранить**. Аккаунт появится в таблице.

Повторите для каждого аккаунта. Все сессии сохраняются в папке `sessions/`.

### 4. Запуск фермы

1. Убедитесь, что в **Настройки → Режим и лимиты** выбран нужный фоновый режим (см. раздел «Режимы работы» ниже).
2. Нажмите кнопку **«Запустить фон»** — все аккаунты начнут работать автоматически с учётом настроек stagger/rate-limiting.

## Режимы работы

Программа поддерживает **три режима** фоновой работы. Режим выбирается в **Настройки → Режим и лимиты → Фоновый режим**.

### Только ручной режим (`manual_only`) — по умолчанию

- Фоновый цикл **отключён**. Кнопка «Запустить фон» не выполняет никаких операций.
- Все действия выполняются **вручную** через кнопки:
  - **Sync now** — синхронизировать состояние выбранного аккаунта (баланс, энергия, холд).
  - **Claim daily** — забрать ежедневную награду.
  - **Play session** — запустить серию ходов (до лимита `max_moves_per_session`).
- Подходит для тестирования и аккуратного контроля отдельных аккаунтов.

### Только чтение (`read_only`)

- Фоновый цикл запускает **синхронизацию** состояния всех аккаунтов каждые ~90 секунд.
- Автоматически обновляет энергию, золото, статус в таблице.
- **Не выполняет** никаких действий: не забирает награды, не делает ходы.
- Ручные кнопки по-прежнему работают.
- Подходит для мониторинга без вмешательства.

### Полный автомат (`full_auto`)

- Фоновый цикл **полностью автоматизирован** для всех аккаунтов:
  - ✅ Синхронизация состояния
  - ✅ Ежедневные награды (claim daily)
  - ✅ Сезонные награды (season pass)
  - ✅ Автоматический refresh состояния после действий
- Каждый аккаунт работает в своём потоке с рандомизированным stagger (2–5 сек между запусками).
- Ограничения:
  - `daily_move_budget` — максимум ходов в день на аккаунт.
  - `max_moves_per_session` — максимум ходов за одну серию.
  - `session_duration_minutes` — лимит длительности фоновой сессии (0 = без ограничения).
  - `quiet_hours` — тихие часы, когда фон не работает.
- **Рекомендуемый режим** для полноценной работы.

## Ручные действия

Кнопки в панели инструментов работают для **выбранного аккаунта** в таблице, независимо от фонового режима:

| Кнопка | Действие |
|---|---|
| **Sync now** | Получить актуальное состояние (энергия, золото, баланс) |
| **Claim daily** | Забрать ежедневную награду (если доступна) |
| **Play session** | Запустить серию ходов с кубиком |
| **Ввести код** | Ввести промокод для всех аккаунтов |
| **Запустить фон** | Запустить фоновый цикл для всех аккаунтов |
| **Остановить фон** | Остановить фоновый цикл |

## Конфигурация

### config.yaml

```yaml
telethon:
  api_id: 12345678       # ОБЯЗАТЕЛЬНО — получите на https://my.telegram.org
  api_hash: 'your_hash'  # ОБЯЗАТЕЛЬНО — получите на https://my.telegram.org

compliance:
  background_mode: full_auto      # manual_only | read_only | full_auto
  session_duration_minutes: 0     # 0 = без ограничения
  quiet_hours_enabled: false
  daily_move_budget: 30
  max_moves_per_session: 8

telegram:
  bot_token: ''      # Telegram Bot API token для уведомлений
  chat_id: ''        # ID чата для уведомлений
```

### accounts.yaml

Управляется через GUI (кнопка «Добавить аккаунт»). Каждый аккаунт имеет:
- `label` — уникальное имя
- `telethon_session` — путь к `.session` файлу
- `proxy_url` — прокси (опционально)
- `install_uuid` — UUID установки (генерируется автоматически)

## Архитектура

```
main.py → PySide6 QApplication
  └─ MainWindow
       ├─ BotWorker (фоновый поток-супервизор)
       │    └─ per-account threads (по одному на аккаунт)
       │         └─ GameeClient
       │              └─ CurlCffiGameeTransport
       │                   ├─ curl_cffi.Session (HTTP/TLS Android Chrome)
       │                   ├─ TelegramWebViewJSRuntime (V8 sandbox)
       │                   └─ InputTelemetryGenerator (синтетические события)
       ├─ AccountActionThread (ручные действия)
       └─ SettingsDialog / AddAccountDialog
```

### Ключевые технологии

| Слой | Технология |
|---|---|
| GUI | PySide6 (Qt 6) |
| Telegram MTProto | Telethon |
| HTTP/TLS | curl_cffi (Android Chrome impersonation) |
| JS Sandbox | py_mini_racer (V8) |
| Конфигурация | PyYAML |

### Rate Limiting

Все запросы проходят через систему ограничений:
- Максимум **2 параллельных** HTTP-запроса.
- Минимум **0.8 сек** между запросами + случайный jitter до **1.2 сек**.
- Stagger между запуском потоков аккаунтов: **2–5 сек**.
- Пауза между циклами синхронизации: **~90 секунд**.

Все эти файлы добавлены в `.gitignore`.
